Memory Notes

    
    
      
  • As long as you hold a reference to a counter/quiz instance, its closed-over state stays alive.
    • 
      
  • Don’t capture DOM nodes inside closures of your logic module; keep logic and rendering separate (as here).
    • 
      
  • Prefer snapshots (plain data) when persisting; dispose or drop references when done.
    • 
      
  • Use WeakMap for metadata keyed by objects you don’t own to reduce leaks.
